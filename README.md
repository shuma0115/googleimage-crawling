# Google Image Crawling

Tampermonkey에서 실행하는 Google 이미지 자동 수집 스크립트로, 검색 결과의 원본 뷰어를 순차적으로 열고 다운로드까지 처리합니다.

## 핵심 기능

- **원본 우선 수집**: 썸네일을 클릭해 뷰어를 열고, 뷰어에 표시된 원본 URL을 우선 수집합니다. 뷰어가 없거나 로딩에 실패한 경우 썸네일의 메타 데이터에서 URI를 추출합니다.
- **필터링 설정**: JPG·PNG·GIF·WEBP·SVG 등 원하는 확장자만 다운로드하도록 설정하고, 최소 가로/세로 크기 기준을 적용할 수 있습니다.
- **저장 경로 & 파일명 제어**: 검색어 기반 기본 폴더/파일명을 사용하거나, “직접 입력” 체크박스로 사용자 지정합니다. 다운로드는 `images/<하위경로>/<파일명>` 형태로 이루어집니다.
- **예약 키워드 & 자동 흐름**: 여러 검색어를 줄단위로 입력한 뒤 자동으로 연속 수집하며, 검색 완료 후 자동으로 다음 예약어를 실행합니다.
- **랜덤 지연 & 주기적 휴식**: 각 다운로드 사이에 지연을 두고, 지정 개수마다 대기 시간을 넣어 Google 부하를 분산합니다. 설정 패널의 슬라이더로 손쉽게 조정 가능합니다.
- **실패 로그 & 상태 표시**: “실패 URL 로그 출력” 옵션을 켜면 필터링/다운로드 실패 URL을 콘솔에 출력하고, 패널 하단에는 수집·다운로드·필터 수를 실시간 표시합니다.

## 설치

1. Chrome/Edge에서 Tampermonkey 확장 프로그램을 설치합니다.
2. Tampermonkey 대시보드에서 “새 스크립트”를 만들고 기본 내용을 지웁니다.
3. `userscript/googl-eimage-crawling.js` 전체를 복사해 붙여넣고 저장합니다.

## 사용 방법

1. Google 이미지 검색 페이지 열기 (예: `https://www.google.com/search?udm=2&q=제주도+숲`).
2. 오른쪽 패널에서 검색어, 확장자/사이즈 필터, 저장 경로를 확인하고 필요한 값을 조정합니다.
3. `원본 자동 수집` 버튼을 눌러 스크립트가 페이지를 스크롤하며 뷰어를 열고 원본을 다운로드하도록 합니다.
4. 수집 중단이 필요하면 버튼을 다시 눌러 “자동 수집 중지”로 전환합니다.
5. 예약 검색을 사용하려면 “예약 키워드” 영역에 검색어를 한 줄씩 입력한 뒤 `예약 키워드 진행` 체크박스를 켭니다. 하나의 검색이 끝나면 다음 검색으로 자동 이동합니다.

## 환경 설정

- **저장 경로**: 검색어 기반 하위 폴더(기본 `images/<검색어>`)가 자동 적용되며, 필요하면 “폴더명 직접 입력” 체크 후 변경합니다.
- **파일명 접두어**: 기본 `image-0001` 형태이며 자동 증가합니다. “파일명 직접 입력” 체크하면 기본 접두어를 수동으로 수정할 수 있습니다.
- **랜덤 딜레이**: `랜덤 지연 활성화`를 체크하면 각 이미지 사이에 설정한 범위(`지연 최소/최대`) 안에서 임의 지연을 넣습니다. “배치당” 개수 이후 `대기 시간`을 추가로 줍니다.
- **확장자 필터**: 필요한 확장자만 선택하고, 미선택 항목은 다운로드에서 제외됩니다.
- **최소 크기**: 뷰어가 없는 썸네일 URI에 대해 `너비/높이` 기준을 적용해 작은 이미지를 걸러냅니다(뷰어가 화면에 표시된 경우 크기 필터를 건너뜁니다).
- **디버그 로그**: “실패 URL 로그 출력”을 활성화하면 개발자 콘솔(`F12`)에 실패한 URL이 찍힙니다.

## Tampermonkey 고급 설정

1. Tampermonkey의 Settings > Config mode를 `Advanced`로 변경합니다.
2. Downloads 섹션에서 Download mode를 `Browser API`로 설정하면 Tampermonkey가 직접 하위 폴더로 저장합니다.

## 주의 사항

- 스크립트는 Google 이미지 검색 페이지의 구조에 매우 의존하므로 Google 디자인이 바뀌면 작동하지 않을 수 있습니다. `getThumbnailElements`나 `findViewerUrl` 내부 선택자를 확인해야 합니다.
- 다운로드는 브라우저의 기본 다운로드 위치를 기준으로 이루어지므로, 하위 폴더로 저장하려면 브라우저(또는 Tampermonkey) 환경 설정을 조정하세요.
- 너무 빠른 반복 실행은 Google의 임시 차단을 유발할 수 있으므로 적절한 대기 설정을 유지하세요.
- 이미지 사용에 따른 저작권/사용 권한을 반드시 확인하고 준수하세요.
