# Google Image Crawling

Tampermonkey에서 구글 이미지 검색 페이지를 향해 작동하는 자동 수집 도구입니다. 우측 패널에서 설정을 조절한 뒤 “원본 자동 수집”을 클릭하면, 썸네일을 순차적으로 클릭하여 뷰어의 원본 이미지 URL을 확보하고 자동으로 다운로드를 시도합니다. 백그라운드에서도 최대한 작업이 이어지도록 타이머와 타겟 감지를 보완했습니다.

## 현재 핵심 기능

- **뷰어/메타 원본 취득**: 뷰어 이미지(`img.n3VNCb` 등)를 우선 확인하고, 뷰어가 없으면 썸네일의 `data-ou`, `data-iv`, `href` 등의 메타 데이터에서 URL을 추출합니다.
- **확장자·크기 필터**: JPG/PNG/GIF/WEBP/SVG 중 선택한 확장자만 허용하고, 뷰어가 아닌 썸네일 URI에는 최소 가로/세로 크기를 적용해 작은 이미지는 배제합니다.
- **자동 경로·파일명 관리**: 검색어에서 폴더(`images/<검색어>`) 및 파일명(`image-0001`)을 자동 생성하고, “직접 입력” 체크박스로 원하는 경로/파일명 접두어를 강제로 적용할 수 있습니다.
- **예약 키워드/자동 이어받기**: 예약 키워드를 줄단위로 입력하고 `예약 키워드 진행`을 켜면, 현재 검색 흐름이 끝난 뒤 다음 키워드로 자동 검색 및 수집을 이어갑니다.
- **랜덤 지연과 대기**: “랜덤 지연 활성화”를 켜면, 이미지마다 설정된 최소/최대(ms) 범위에서 지연을 넣고, 지정 개수마다 `대기 시간`을 갖춰 Google에 대한 부하를 분산합니다. 탭이 숨겨진 상태에서도 의도된 지연이 유지되도록 조치했습니다.
- **진행 상태·디버그 로그**: 패널 하단에 수집·다운로드·필터 제외 수를 실시간 표시하고, `실패 URL 로그 출력`을 켜면 실패 URL이 브라우저 콘솔에 기록됩니다.

## 설치/배포

1. Chrome 또는 Edge에서 Tampermonkey 확장 프로그램을 설치합니다.
2. Tampermonkey 대시보드에서 “새 스크립트 만들기”를 선택하고 기본 코드를 전부 지웁니다.
3. 본 레포지토리의 `userscript/googl-eimage-crawling.js` 전체를 복사해 Tampermonkey 에디터에 붙여넣고 저장합니다.
4. 다운로드 폴더에 `images/` 하위 경로를 자동 생성하려면 Tampermonkey 설정에서 다운로드 모드를 `Browser API`로 변경하세요.

## 사용 흐름

1. Google 이미지 검색 결과(예: `https://www.google.com/search?udm=2&q=여행지`)를 엽니다.
2. 오른쪽 패널에서 검색어, 예약 키워드, 저장 경로, 확장자/크기 필터 등을 조정합니다.
3. `원본 자동 수집` 버튼을 눌러 자동 수집을 시작합니다. 스크롤을 반복하며 썸네일을 클릭하고, 뷰어와 메타 데이터를 순차 처리합니다.
4. 수집 중지 또는 임시 정지가 필요하면 `자동 수집 중지` 버튼을 클릭합니다.
5. 예약 키워드를 설정한 경우 한 검색이 끝나면 다음 예약어로 자동 이동하며, `자동 시작` 옵션을 켜면 검색 시 바로 수집을 시작합니다.

## 설정 설명

| 항목 | 설명 |
| --- | --- |
| **저장 폴더** | 검색어 기반으로 `images/<검색어>`를 기본값으로 사용. `폴더명 직접 입력`을 체크하면 원하는 경로로 덮어쓸 수 있습니다. |
| **파일명 접두어** | `image-0001`처럼 자동 증가. 직접 입력을 활성화하면 원하는 템플릿을 사용합니다. |
| **확장자 필터** | 체크된 확장자만 다운로드. 미선택 확장자는 자동 필터링됩니다. |
| **최소 크기** | `뷰어 없음` 상황에서 가져온 이미지에 대해 너비/높이 기준으로 필터링합니다. |
| **랜덤 지연** | `지연 최소/최대(ms)` 내부에서 랜덤 간격을 두고, `배치당` 개수 마다 `대기 시간`을 넣습니다. 탭이 배경에 있을 때도 지연이 유지됩니다. |
| **디버그 로그** | 실패한 URL과 오류를 console에 출력해서 문제를 진단하기 쉽도록 합니다. |

## Tampermonkey 고급 설정

1. Tampermonkey 설정(Settings) → `Config mode`를 `Advanced`로 전환합니다.
2. `Downloads` 섹션에서 `Download mode`를 `Browser API`로 설정하면, 제공된 하위 폴더 이름(`images/...`)대로 실제 다운로드 경로를 유지합니다.
3. 한 번에 많은 이미지를 저장할 때는 `Tampermonkey > General`의 `Maximum downloads per session`도 늘리는 것을 고려하세요.

## 문제 해결 팁

- **뷰어가 열리지 않거나 다운로드가 실패**하면 `F12` 콘솔에서 `[GI-IMG]` 로그를 확인하고, 뷰어/섬네일 선택자(`findViewerUrl`, `getThumbnailElements`)가 Google UI 변경으로 깨졌는지 확인합니다.
- **이미지 URL이 CORS 등으로 막힐 때**는 `실패 URL 로그 출력`을 켜고 다운로드 링크를 새 탭에서 수동으로 테스트해보세요.
- **자동 수집이 안 켜질 때**는 Tampermonkey의 `Storage`를 초기화하거나 `sessionStorage` 내 `gi-auto-start-pending` 값을 확인해서 자동 시작 플래그를 재설정합니다.

## 참고

- 이 스크립트는 Google 이미지 검색이 사용하는 DOM 구조에 크게 의존하므로, Google이 UI를 변경하면 `findViewerUrl`, `getThumbnailElements`, `viewer url` 검출 로직을 다시 점검해야 합니다.
- 수집한 이미지 사용 시 저작권 및 Google 정책을 반드시 확인하고 준수하세요.
